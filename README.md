# StayNest 🏡

### Property Listing Platform

StayNest is a full-stack web application inspired by Airbnb. It allows users to explore property listings, create and manage their own listings, and share reviews.

## ✨ Features

* **User Authentication:** Signup and login using Passport.js.
* **Listing Management:** Create, view, edit, and delete property listings.
* **Image Uploads:** Upload listing images using Multer and Cloudinary.
* **Reviews:** Add and delete reviews for property listings.
* **Authorization:** Restrict listing and review operations to authorized users.
* **Session Management:** Maintain persistent user sessions using MongoDB.
* **Input Validation:** Validate user-submitted data using Joi.
* **Flash Messages:** Display success and error notifications.

## 🛠️ Tech Stack

* **Frontend:** EJS, HTML, CSS, Bootstrap, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Authentication:** Passport.js, express-session
* **Image Storage:** Cloudinary, Multer
* **Validation:** Joi

## 🧠 Key Concepts

* MVC architecture and RESTful routing
* CRUD operations using Express and Mongoose
* Authentication and authorization middleware
* MongoDB relationships using references and `populate()`
* Asynchronous error handling
* Image uploads and cloud storage
* Session persistence using MongoDB
* Server-side rendering with EJS
